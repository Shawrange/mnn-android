# Gate2-C3 单Q投影独立数值验证协议

固定MNN commit7e3c6fb5225d3ccf22807ee641332669df34650d及原模型。只使用C2两份已验证q_input（8/13 Token ×1024），只执行第一层q_proj，输出2048维。CPU基线库、GPU clean库及模型只读；新独立worktree/诊断分支保留最小补丁。无性能优化、全模型扩展、GPU性能基线或NPU。

先确认实际函数指针/pack/量化分组。Tracing只复制必要buffer到独立内存，离开计算后写文件；环境变量缺省关闭。Tracing on/off输出逐字节比较，正式性能不从Tracing得出。每次执行前重新上传固定输入，实际executor入口与源一致才用于归因。首轮及随后执行都保存，不将before callback无效读数当作kernel输入。

主机独立A：读取原外置权重段、独立解码INT4及alpha、加相同bias，FP64矩阵乘。主机独立B：按实测ARM规则重建整数输入/scale，分块整数点积与对应权重scale/offset、输入反量化及Bias；同时给出理想FP64量化表达式与遵从实际FP32/FP16步骤的结果。FP64是同一量化权重的参照，不是未量化黄金模型。

量化契约核验分开：输入整数逐元素一致，scale/zero等参数对照，原权重独立解码与Runtime解码逐元素核对。输出记录rRMSE、cosine、max/mean abs、范围、finite及差分分布。先以重建中间参数的精确一致和输出类型舍入误差解释为目标，不继承Logits门禁充当单算子官方容差。任何新增数值容差须说明推导，不追溯改变C1/C2阈值。

停止：A预期量化语义解释→结束此算子定位、后续仅模型质量验收；B可重复不一致→先最小复现/回归，不直接修Runtime；C缺失关键证据→列明缺口和价值，不无限扩展。
